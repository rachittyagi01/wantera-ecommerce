# WANTERA

**Want It. Find It. Love It.**

A full-stack e-commerce platform built with React, TypeScript, Node.js, Express, MongoDB, and Razorpay.

> 🚧 This project is under active development, built phase-by-phase.
> Full documentation, screenshots, and setup instructions will be added as features are completed (see Phase 25).

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui, Redux Toolkit
- **Backend:** Node.js, Express, TypeScript
- **Database:** MongoDB Atlas + Mongoose
- **Payments:** Razorpay (Test Mode)
- **Images:** Cloudinary

## Status

Currently in early development. See commit history for progress.
